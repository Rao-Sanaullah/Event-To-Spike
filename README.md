# Event-To-Spike for Spiking Neural Network Community
An ongoing project in which the conversion of DVX346 camera using Baxter robot-generated event-based datasets into spike train datasets,  
The research focuses on two aspects: 

(1) providing spike train datasets for the SNN research community exploration, and 

(2) exploring the limits of converting asynchronous datasets into synchronized datasets.
